# Dialog

현재 흐름을 멈추고 확인 또는 추가 입력이 필요한 modal dialog를 구성하는 compound 컴포넌트입니다.

<h2 id="usage">사용 기준과 기본 예제</h2>

### 사용할 때

- 삭제 확인처럼 사용자의 즉각적인 주의와 명시적 결정을 요구할 때 사용합니다.
- 현재 화면 위에서 독립된 입력 또는 확인 흐름을 제공해야 할 때 사용합니다.

### 사용하지 않을 때

- 간단한 보조 설명에는 `Tooltip`, trigger 가까이의 짧은 보조 action에는 `Popover`를 사용합니다.
- Dialog 내부에 product 전용 title, close icon, action을 강제하지 않습니다.

<h2 id="composition">modal 구조와 action</h2>

`Root`, `Trigger`, `Portal`, `Overlay`, `Content` 안에 `Header`, `Title`, `Description`, `Footer`, `Close`를 필요한 만큼 조합합니다. close control은 `Dialog.Close asChild`로 consumer Button과 연결할 수 있습니다.

<Canvas of={DialogStories.Interaction} sourceState="shown" />

<h2 id="props">주요 API와 state</h2>

`Root`는 `open`, `defaultOpen`, `onOpenChange`, `modal`을 Radix 계약대로 지원합니다. Portal은 overlay layer를, Content는 native props와 ref를 담당하며 Header와 Footer는 layout `div`입니다.

<Controls of={DialogStories.Playground} />

<h2 id="accessibility">접근성</h2>

- Content에는 `Title`을 반드시 제공하고, 필요한 설명은 `Description`으로 연결합니다.
- Escape로 닫히고 focus trap을 유지하며, 닫힌 뒤 Trigger로 focus가 복귀합니다.
- Dialog의 action은 keyboard로 모두 접근 가능해야 하며, 파괴적 action의 영향은 text로 분명히 설명합니다.

<h2 id="tokens">토큰 커스터마이징</h2>

Dialog surface와 layer는 `--dds-dialog-bg`, `--dds-dialog-radius`, `--dds-dialog-shadow`, `--dds-dialog-overlay`, `--dds-z-index-modal` token을 사용합니다.

```css
[data-dds-brand="project"] {
  --dds-dialog-radius: var(--dds-radius-xl);
  --dds-dialog-overlay: var(--dds-color-bg-overlay);
}
```
