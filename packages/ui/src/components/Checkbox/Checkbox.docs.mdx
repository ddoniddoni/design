# Checkbox

서로 독립적인 true/false 또는 indeterminate 선택을 제공하는 control입니다.

<h2 id="usage">사용 기준과 기본 예제</h2>

### 사용할 때

- 약관 동의나 여러 알림 항목처럼 값을 각각 독립적으로 선택할 때 사용합니다.
- 일부만 선택된 상위 항목을 `indeterminate`로 표현할 때 사용합니다.

### 사용하지 않을 때

- 여러 항목 중 하나만 선택해야 하면 `RadioGroup`을 사용합니다.
- 변경 즉시 효력이 발생하는 단일 설정에는 `Switch`를 사용합니다.

<h2 id="props">주요 props와 native props</h2>

`checked`, `defaultChecked`, `onCheckedChange`, `disabled`, `name`, `value`, `required`, `id`와 aria props를 지원합니다. 실제 focus 대상은 native button 역할의 Checkbox root입니다.

<Controls of={CheckboxStories.Uncontrolled} />

<h2 id="accessibility">접근성</h2>

- 외부 `<label htmlFor>` 또는 `aria-label`로 accessible name을 제공합니다.
- Space로 선택을 전환하며 `checked`, `unchecked`, `indeterminate` 상태가 보조기술에 전달됩니다.
- label wrapper는 `align-items: center`와 `--dds-space-2` gap으로 구성합니다. Checkbox 자체에 외부 margin을 강제하지 않습니다.
- disabled 이유가 중요하면 control 가까이에 텍스트로 설명합니다.

<h2 id="tokens">토큰 커스터마이징</h2>

surface와 focus는 `--dds-input-*`을 사용하고 checked/indeterminate mark는 `--dds-checkbox-indicator`를 사용합니다.

```css
[data-dds-theme="dark"] {
  --dds-checkbox-indicator: var(--dds-color-neutral-0);
  --dds-input-border-focus: var(--dds-color-brand-400);
}
```
