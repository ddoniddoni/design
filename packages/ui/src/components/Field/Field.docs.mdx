# Field

label, control, 설명, 오류 메시지를 명시적으로 조합하는 form layout 컴포넌트입니다.

<h2 id="usage">사용 기준과 기본 예제</h2>

### 사용할 때

- 입력 control에 visible label과 보조 설명 또는 오류를 연결할 때 사용합니다.
- Input과 Textarea가 같은 form 정보 구조를 유지해야 할 때 사용합니다.

### 사용하지 않을 때

- control의 value, invalid, disabled 상태를 자동으로 관리하는 wrapper로 사용하지 않습니다.
- label이 없는 단독 control에는 각 control의 `aria-label`을 제공합니다.

<h2 id="composition">설명과 오류 조합</h2>

`Field.Root`의 `invalid`, `disabled`는 label과 보조 text의 시각 상태만 표현합니다. 실제 Input 또는 Textarea에도 같은 state와 `aria-describedby`를 명시적으로 전달합니다.

<h2 id="props">주요 props와 native props</h2>

`Root`, `Label`, `Description`, `Error`는 각각 native `div`, `label`, `p`, `p` props와 ref를 전달합니다. Root의 `invalid`, `disabled`는 control의 native state를 바꾸지 않습니다.

<h2 id="accessibility">접근성</h2>

- `Field.Label htmlFor`와 control `id`를 연결해 label click과 accessible name을 제공합니다.
- 설명 또는 오류의 `id`를 control `aria-describedby`에 연결합니다.
- 오류는 자동 live region이 아닙니다. validation을 언제 알려 줄지는 form 흐름에 맞춰 결정합니다.
- disabled와 invalid의 실제 semantics는 control에 별도로 전달합니다.

<h2 id="tokens">토큰 커스터마이징</h2>

Field의 text와 spacing은 `--dds-color-text-*`, `--dds-color-status-danger-text`, `--dds-font-*`, `--dds-space-2` semantic token을 사용합니다.

```css
[data-dds-theme="dark"] {
  --dds-color-text-secondary: var(--dds-color-neutral-300);
  --dds-color-status-danger-text: var(--dds-color-danger-400);
}
```
