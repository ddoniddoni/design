# Table

열 간 비교가 필요한 구조화된 데이터를 native table semantics로 표시하는 compound 컴포넌트입니다.

<h2 id="usage">사용 기준과 기본 예제</h2>

### 사용할 때

- 프로젝트, 멤버, 활동처럼 여러 행과 열의 값을 비교해야 할 때 사용합니다.
- caption과 column header를 제공할 수 있는 정형 데이터를 표시할 때 사용합니다.

### 사용하지 않을 때

- 한두 개의 값만 강조하는 목록에는 Card 또는 일반 list를 사용합니다.
- sorting, selection, filtering, virtualization을 내장한 DataGrid가 필요한 경우에는 사용하지 않습니다.

<h2 id="composition">semantic table 구조</h2>

`Container`는 좁은 영역의 가로 scroll을 담당하고, 그 안에 `Root`, `Caption`, `Header`, `Body`, `Row`, `Head`, `Cell`을 native table 순서로 조합합니다. 필요하면 `Footer`를 추가합니다.

<h2 id="props">주요 API와 native props</h2>

각 하위 component는 대응하는 `div`, `table`, `caption`, `thead`, `tbody`, `tfoot`, `tr`, `th`, `td`를 렌더링합니다. `scope`, `colSpan`, `rowSpan`, `headers` 등 native table attributes와 `className`, ref를 그대로 전달합니다.

<h2 id="accessibility">접근성</h2>

- `Caption`으로 table의 주제와 목적을 제공합니다.
- column header에는 `Table.Head scope="col"`, row header에는 `scope="row"`를 명시합니다.
- 좁은 화면에서는 `Container`가 가로 scroll을 제공합니다. 중요한 열을 숨기기보다 table 구조와 header 관계를 유지합니다.

<h2 id="tokens">토큰 커스터마이징</h2>

Table의 surface, caption, header, row hover는 `--dds-table-*` token으로 조정합니다.

```css
[data-dds-brand="project"] {
  --dds-table-header-bg: var(--dds-color-brand-50);
  --dds-table-row-hover-bg: var(--dds-color-brand-50);
}
```
