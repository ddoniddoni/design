# Accordion

독립적인 보조 콘텐츠를 필요할 때 펼쳐 보는 disclosure 컴포넌트입니다.

<h2 id="usage">사용 기준과 기본 예제</h2>

### 사용할 때

- FAQ, 설정 안내처럼 서로 독립적인 여러 섹션을 접고 펼칠 때 사용합니다.
- 긴 페이지의 보조 정보를 처음에는 간결하게 유지해야 할 때 사용합니다.

### 사용하지 않을 때

- 동등한 콘텐츠 영역을 한 번에 하나씩 전환할 때는 `Tabs`를 사용합니다.
- 순서가 중요한 단계형 흐름에는 별도 stepper 또는 form 흐름을 사용합니다.

<h2 id="composition">단일·복수 열림 상태</h2>

`Root` 안에서 `Item`, `Header`, `Trigger`, `Content`를 순서대로 조합합니다. `type="single"`은 한 항목을, `type="multiple"`은 여러 항목을 열 수 있습니다. state가 필요하면 `value`와 `onValueChange`를 consumer가 제어합니다.

<h2 id="props">주요 API와 state</h2>

`Root`는 `type`, `value`, `defaultValue`, `onValueChange`, `collapsible`을 Radix 계약대로 전달합니다. `Item`의 `disabled`를 사용해 열 수 없는 항목을 명시할 수 있고, DOM subcomponent는 native props, `className`, ref를 전달합니다.

<Controls of={AccordionStories.Playground} />

<h2 id="accessibility">접근성</h2>

- `Header`는 heading, `Trigger`는 native button semantics를 유지합니다.
- Arrow key로 Trigger 사이를 이동하며, 열림 상태와 `aria-expanded`/Content 관계는 Radix가 관리합니다.
- 긴 Content에는 heading과 문단 등 의미 있는 구조를 유지하고, Trigger label만으로 내용을 숨기지 않습니다.

<h2 id="tokens">토큰 커스터마이징</h2>

구분선과 open/hover surface는 `--dds-accordion-border`, `--dds-accordion-trigger-hover-bg`, `--dds-accordion-trigger-open-bg` token으로 조정합니다.

```css
[data-dds-brand="project"] {
  --dds-accordion-trigger-open-bg: var(--dds-color-brand-50);
  --dds-accordion-border: var(--dds-color-brand-200);
}
```
