# RadioGroup

서로 배타적인 여러 항목 중 하나의 form 값을 선택하는 control group입니다.

<h2 id="usage">사용 기준과 기본 예제</h2>

### 사용할 때

- 공개 범위, 정렬 방식처럼 적은 수의 옵션을 비교하며 하나만 선택할 때 사용합니다.
- 모든 선택지를 화면에 보여 주어야 판단하기 쉬운 경우 사용합니다.

### 사용하지 않을 때

- 여러 값을 독립적으로 선택할 때는 `Checkbox`를 사용합니다.
- 공간을 절약하는 긴 옵션 목록에는 `Select`를 사용합니다.
- 즉시 적용되는 boolean 설정에는 `Switch`를 사용합니다.

<h2 id="states">제어 상태와 form</h2>

`value`와 `onValueChange`로 제어하거나 `defaultValue`로 초기 선택을 지정합니다. `name`과 `required`는 form value에 연결됩니다.

<h2 id="props">주요 props와 native props</h2>

`Root`는 value state, `name`, `required`, accessible name을 받고 `Item`은 `value`, `disabled`, `id`와 native props 및 ref를 전달합니다.

<Controls of={RadioGroupStories.Playground} />

<h2 id="accessibility">접근성</h2>

- `Root`에 `aria-label` 또는 `aria-labelledby`를 제공하고, 각 Item은 외부 `<label htmlFor>`와 연결합니다.
- Arrow key로 항목 사이를 이동하고 선택 상태는 Radix가 관리합니다.
- item과 label은 `align-items: center` 및 `--dds-space-2` gap을 사용하는 consumer wrapper에서 조합합니다.
- disabled 항목을 선택 가능해 보이게 만들지 않고, 필요하면 disabled 이유를 설명합니다.

<h2 id="tokens">토큰 커스터마이징</h2>

RadioGroup은 `--dds-input-*`, `--dds-radio-indicator`, `--dds-focus-ring-*` token을 사용합니다.

```css
[data-dds-theme="dark"] {
  --dds-radio-indicator: var(--dds-color-neutral-0);
  --dds-input-border-focus: var(--dds-color-brand-400);
}
```
