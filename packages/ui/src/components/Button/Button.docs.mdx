# Button

사용자의 명시적 action을 실행하는 native button 컴포넌트입니다.

<h2 id="usage">사용 기준과 기본 예제</h2>

### 사용할 때

- 저장, 삭제, 확인처럼 현재 화면의 동작을 실행할 때 사용합니다.
- 한 화면에서 대표 action을 명확하게 제시해야 할 때 사용합니다.

### 사용하지 않을 때

- URL만 바꾸는 이동에는 button 대신 link semantics를 사용합니다.
- 텍스트 없이 아이콘만 보여 주는 compact action에는 `IconButton`을 사용합니다.

<h2 id="variants">Variant, tone, size</h2>

`variant`는 표현 방식, `tone`은 action의 의미, `size`는 control의 높이와 글자 크기를 정합니다. 같은 화면에는 primary action을 하나만 두고, 파괴적인 action에는 `danger` tone을 사용합니다.

### Variant

`solid`는 대표 action, `outline`은 보조 action, `ghost`는 주변 UI를 방해하지 않아야 하는 action에 적합합니다.

<Canvas of={ButtonStories.AllVariants} sourceState="shown" />

### Tone

`primary`는 기본 action, `neutral`은 중립 action, `danger`는 삭제처럼 되돌리기 어려운 action을 나타냅니다.

<Canvas of={ButtonStories.AllTones} sourceState="shown" />

### Size

기본값은 `md`입니다. 같은 control group 안에서는 일관된 size를 유지하고, 작은 화면에서만 필요한 경우 `fullWidth`를 조합합니다.

`Button`은 실제 `<button>`에 ref와 `className`, `name`, `form`, `onClick` 등 native button props를 전달합니다. 기본 `type`은 `button`이며, form 제출에는 명시적으로 `type="submit"`을 지정합니다.

<h2 id="accessibility">접근성</h2>

- native `<button>` semantics와 keyboard 동작을 유지합니다. Space 또는 Enter로 action을 실행할 수 있습니다.
- `loading`이면 `aria-busy="true"`와 native `disabled`가 함께 적용됩니다. spinner는 장식 요소이므로 추가 label을 만들지 않습니다.
- `disabled` button은 focus나 click으로 동작하지 않습니다. disabled 이유가 중요하면 control 근처의 설명 텍스트로 제공합니다.
- 텍스트 없는 icon-only action에는 `Button` 대신 접근 가능한 이름이 필수인 `IconButton`을 사용합니다.

<h2 id="tokens">토큰 커스터마이징</h2>

Button의 tone별 배경·hover·active·text는 `--dds-button-primary-*`, `--dds-button-neutral-*`, `--dds-button-danger-*`로 제어합니다. 크기와 radius는 `--dds-control-height-*`, `--dds-control-radius`를 사용합니다.

```css
[data-dds-brand="project"] {
  --dds-button-primary-bg: var(--dds-color-brand-700);
  --dds-button-primary-hover: var(--dds-color-brand-800);
  --dds-button-primary-active: var(--dds-color-brand-900);
  --dds-control-radius: var(--dds-radius-lg);
}
```

토큰은 Button의 source를 수정하지 않고 theme scope에서 override합니다. light, dark, system theme에서도 semantic token의 대비를 함께 확인하세요.
